# QUIZ APPLICATION
A quiz application where users can answer multiple-choice questions, track their score and time, and view the result.

## REQUIREMENTS

1. Quiz Flow

[x]  Start screen with instructions and Start Quiz button.
[x]  Display one question at a time.
[x]  Next and Previous question navigation.
[x]  Show current question number and total questions.
[x]  User cannot skip a question without selecting an option.

2. Questions

[x]  Multiple-choice questions (single correct answer).
[x]  Questions can include text and (optional) images.

3. Timer

[x]  Set a total time for the quiz (e.g., 10 minutes).
[x]  Show remaining time.
[x]  Auto-submit the quiz when time is up.

4. Score Calculation

[x]  Each correct answer gives 1 point.
[x]  Incorrect answers give 0 points.
[x]  Calculate total score and percentage.

5. Result Screen

[x]  Display total score, percentage, and performance level.
[x]  Show correct, incorrect, and unattempted counts.
[x]  Options to restart quiz or go to home.

6. Review Answers (Optional but Recommended)

[x]  After quiz completion, show review of all questions with:
    [x]  Correct answer
    [x]  User's answer
    [x]  Whether it was correct or incorrect

7. Data

[x]  Questions can be stored in a JavaScript file (JSON format).

8. Additional Features

[]  Progress bar to show completion.
[]  Responsive design for mobile and desktop.
[]  Clean UI with good user experience.
