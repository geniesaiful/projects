# QUIZ APPLICATION
A quiz application where users can answer multiple-choice questions, track their score and time, and view the result.

## REQUIREMENTS


1. Quiz Flow

[]  Start screen with instructions and Start Quiz button.
[]  Display one question at a time.
[]  Next and Previous question navigation.
[]  Show current question number and total questions.
[]  User cannot skip a question without selecting an option.

2. Questions

[]  Multiple-choice questions (single correct answer).
[]  Questions can include text and (optional) images.

3. Timer

[]  Set a total time for the quiz (e.g., 10 minutes).
[]  Show remaining time.
[]  Auto-submit the quiz when time is up.

4. Score Calculation

[]  Each correct answer gives 1 point.
[]  Incorrect answers give 0 points.
[]  Calculate total score and percentage.

5. Result Screen

[]  Display total score, percentage, and performance level.
[]  Show correct, incorrect, and unattempted counts.
[]  Options to restart quiz or go to home.

6. Review Answers (Optional but Recommended)

[]  After quiz completion, show review of all questions with:
[]  Correct answer
[]  User's answer
[]  Whether it was correct or incorrect

7. Data

[]  Questions can be stored in a JavaScript file (JSON format).

8. Additional Features

[]  Progress bar to show completion.
[]  Responsive design for mobile and desktop.
[]  Clean UI with good user experience.
