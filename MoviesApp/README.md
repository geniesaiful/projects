# Movies App

## Core Features

- [] Search movies by name
- [] Fetch movies from a public API
- [] Display movie cards
- [] Show movie details
- [] Poster image
- [] Release year
- [] Rating
- [] Genre
- [] Plot/description
- [] Loading state
- [] Error state
- [] Pagination or "Load More"
- [] Recent searches
- [] Favorites/watchlist using Local Storage
